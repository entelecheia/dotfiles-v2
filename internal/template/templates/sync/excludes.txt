# Static exclude rules for `dot sync` (junk layer).
#
# Layered with the other filter mechanisms:
#   - submodules.dyn.conf     submodule paths (synced via Git, regenerated per run)
#   - built-in secrets layer  /.secrets, /.maru/secrets, .env* — allow.txt opts in
#   - ignore.txt              operator-specific excludes
#   - tracked-includes.dyn.conf + include.txt   the union include layers
#   - `--no-links` skips all symlinks
# `.gitignore` is intentionally not a sync filter: Git-ignored binaries are a
# primary sync payload. This file is the always-on junk baseline.
