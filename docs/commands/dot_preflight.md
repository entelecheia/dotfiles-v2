## dot preflight

Check environment and generate config

### Synopsis

Run environment checks and generate a dot configuration based on the detected system.

```
dot preflight [flags]
```

### Options

```
      --check-only   Only run checks, don't generate config
      --force        Overwrite existing config file
  -h, --help         help for preflight
```
